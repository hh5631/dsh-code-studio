# dsh-code-studio

融入 DSH 原生文件区的轻量编辑器：在文件树旁编辑代码和 Markdown，查看 Git 修改。

## 使用

- 打开 DSH 的“工作区文件”，点击文本文件后直接在原生文件页签编辑，文件树位于内容旁边。
- 移除独立的“文件编辑”入口和插件内部文件页签栏。文件名、导航和文件树展开状态由 DSH 管理。
- 从旁边的文件树选择另一个文件时，在当前页签切换内容；保存失败会保留当前文件，连续点击只提交最后一次选择。
- 宽屏首次进入会显示原生文件树，可通过文件夹按钮收起；窄屏沿用 DSH 的覆盖和收起规则。
- 文件页保留 DSH 的视图选择、换行、刷新、打开方式与文件树工具，右端增加 Git 和搜索。常见文本与代码文件可在视图选择中切换编辑器和原生预览。
- 在 DSH 设置 → 代码工作台中修改编辑器字体、字号和插件界面字体、字号，离开输入框保存并即时生效。留空跟随宿主；使用当前设备已有字体。
- 输入后自动保存，也可使用保存快捷键。保存失败或外部修改冲突时保留本地内容。
- 在 Git 面板点击已跟踪的变更文件查看 patch，区分已暂存和未暂存。未跟踪文件直接打开。
- 图片、PDF、Office 由 DSH 原生预览；不再加载插件内的表格、PDF 编辑器。
- 较大的文本采用只读分页预览，避免创建过大的 Monaco 模型。

## 性能与数据保护

同一个编辑区复用 Monaco 实例，已打开文件复用模型与撤销历史。并发读取合并，输入时不把全文复制到 React 状态；保存按文件防抖。切换文件或窗口重新聚焦时校验磁盘版本，没有差异审查心跳或逐文件后台轮询。

通过旁边的原生文件树切换内容前先保存。原生页签关闭后，失败的保存仍保留本地缓冲，并阻止直接刷新页面；可重新打开原文件处理。外部修改冲突时停止自动保存，可以复制本地内容或明确重新加载。历史聊天、磁盘文件与既有审查归档不会因功能精简被删除。

## 已移除

Agent 编辑采集、累计差异基线、Keep/Undo、差异装饰、审查浮层、差异历史与回滚入口；多编辑分组/浮动编辑窗口；额外的大纲、诊断窗口、会话体积和会话列表状态入口。Git 仓库修改差异独立保留。

## 安装

构建产物（`lib/`）不随仓库提交，所以推荐安装预构建 tarball：

```sh
dsh plugin --profile web add https://github.com/hh5631/dsh-code-studio/releases/latest/download/dsh-code-studio.tgz
```

也可以从源码安装（需要本地完成一次构建）：

```sh
git clone https://github.com/hh5631/dsh-code-studio.git
cd dsh-code-studio && npm install && npm run build
dsh plugin --profile web add link:$PWD
```

## 构建

```sh
npm run build
```

开发依赖沿用项目现有配置。移除了 Univer、ExcelJS 及其直接配套依赖。构建前请保留现有产物备份；源码检查不代表当前服务已加载新版本。
